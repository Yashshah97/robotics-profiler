# Usage

```python
import robotics_profiler
```

Each module is self-contained; see docstrings for the API:

- `robotics_profiler.profiler` — Core instrumentation logic and API
- `robotics_profiler.kinematics` — Kinematics module for calculating robot movements
- `robotics_profiler.path_planning` — Path planning module for generating motion plans
- `robotics_profiler.reporting` — Flame-style text reporting functionality
- `robotics_profiler.util` — Utility functions and constants used throughout the library
- `robotics_profiler.test_profiler` — Unit tests for the profiler module
